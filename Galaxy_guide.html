Before you launch

Open the right file

Two files, same features. The difference is where the game data lives.

🪐 BGG_Galaxy.html — use this one

Every game's box art, rating and genre is stored inside the file. Works with no internet, anywhere, forever. This is the file to keep and to share.

🛰️ BG_database.html

A small file that downloads the data when you are online. Fine on the hosted site — but with no connection it has no data and shows plain planets.

If a page ever says “no built-in BoardGameGeek data”, you opened the second file offline. Switch to BGG_Galaxy.html.

The most useful trick

Adding a game

Click the hidden + in the middle of the sun to open the add window.

Best way: paste the BoardGameGeek link

Copy the game's address from boardgamegeek.com and paste it straight into the title box:

https://boardgamegeek.com/boardgame/404923/operation-barclay

The galaxy reads the game's ID out of the link, names the game properly, and fills in players, age, artwork and rating. This works even if the connection fails — the ID is in the link itself, so nothing is lost.

Just typing a name

Also fine — it searches for a match. Nicknames and Czech-only names may not be found, so a link is safer.

No internet?

The window says so and the button becomes Add offline (sync later). The game is saved; the details arrive later.

Fixing anything

Edit a game

Open any game and press ✏️ Edit — everything about it can be corrected by hand.

Both titles

English and Czech. The search finds the new names immediately, and renaming never loses the game's BGG data.

Notes

Anything you want to remember: “borrowed to Petr”, “missing 2 cards”.

Alternative URL

For games on neither BGG nor Zatrolené hry — a Kickstarter or publisher link. It appears as a link on the game.

Box art & BGG id

Paste a better image URL, or relink the game to the correct BGG entry and re-fetch everything.

Edits are saved in your browser and win over future syncs. Reset to original BGG data undoes them.
Keeping data fresh

The Sync button

🔄 Sync on a game fetches the newest BoardGameGeek data for it. If it cannot, it tells you exactly why:

⚠️ BoardGameGeek has no match for this title

The name could not be matched. Waiting will not help — open ✏️ Edit and paste the game's BGG link or id.

⚠️ Not in the shared database yet

Only on your computer so far. Press 🚀 Publish first — see the next slide.

⚠️ Could not reach the online database

Just a connection problem. Try again when you are back online.

The footer's Update all from data file refreshes the whole collection in one go.
Sharing your additions

Publish, then sync

Games you add live only in your browser until you publish them.

🚀 Publish additions onlinesends them to the shared collection
  • 1
    Press 🚀 Publish. A GitHub page opens, already filled in.
  • 2
    Press Submit new issue on that page. That is the only button you need — it is the message being sent.
  • 3
    Wait about 5 minutes. A robot adds your games and fetches their BoardGameGeek data.
  • 4
    Read the robot's reply on that page — it names every game and what happened to it.
  • 5
    Back in the galaxy, press 🔄 Sync on those games.
Nothing else on the GitHub page needs your attention. Once the reply appears, the work is done.
Reading the robot's reply

Three possible verdicts

✅ Ready to sync

Found on BoardGameGeek, with a link to prove which game it matched. Press 🔄 Sync and you are done.

⏳ Matched, details still coming

The next run will finish it. Sync again a little later.

⚠️ No match for these titles

Usually a nickname, a Czech-only name or a typo. Find the game on BoardGameGeek, then ✏️ Edit → paste the id → Re-fetch → Save, and publish once more.

This is why pasting a BGG link when adding a game is worth the extra second — a game with an id can always be found.

Bulk work

Excel in, Excel out

📊 Export to Excel

Saves the whole collection and wishlist as a spreadsheet — two sheets, every attribute, ready to share or edit.

📦 Import an updated spreadsheet

Type the secret phrase into the command line at the very top of the page:

usakova sbirka board game database

Pick your .xlsx; only the games that are genuinely new are offered, with tick boxes.

The exported file uses exactly the layout the import expects — so you can export, edit in Excel, and feed it straight back.
The rest of the footer

Housekeeping

  • ⬇️
    Download portable HTML — bakes your current galaxy, edits and all, into a fresh file you can share. Whoever opens it sees your version instantly, offline.
  • 🗑
    Remove — on any game's page. It disappears from view; nothing is destroyed.
  • 🔐
    Restore removed games and Rescan galaxy ask for the maintenance password first — they undo work, so they are behind the same secret phrase as the import.
Everything you do stays in your browser until you press Publish. There is no way to break the shared collection by clicking around.
